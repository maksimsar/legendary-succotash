Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Проверяемые сценарии
--------------------

| Тест | Что проверяет |
| --- | --- |
| `opens` | После нажатия «Помощь» виден контейнер виджета. |
| `has correct title` | Из первой популярной статьи открывается форма с заголовком «Связь с поддержкой». |
| `returns to popular articles from an article` | Кнопка возврата открывает список популярных статей. |

Тест-кейс TC-3 — Возврат из статьи к популярным статьям - создан дополнительно, поэтому опишем еще и тест-кейс для него. 
--------------------------------------------------------------

Автотест: `returns to popular articles from an article` в `tests/widget.spec.ts`.

**Предусловия:** пользователь не авторизован, открыта главная страница
`https://uchi.ru/`, окно cookies закрыто, виджет поддержки доступен и содержит
хотя бы одну популярную статью. Каждый тест использует отдельный браузерный контекст.

**Шаги:**

1. Открыть виджет кнопкой «Помощь».
2. Открыть первую статью в разделе «Популярные статьи».
3. Дождаться появления кнопки «Написать нам» на экране статьи.
4. Нажать кнопку «Назад» в заголовке виджета.

**Ожидаемый результат:** снова видны популярные статьи и кнопка
«Смотреть все статьи», а кнопка «Написать нам» скрыта.

Примечание
-------------------------

В DOM для кнопок виджета есть `data-test`, для элементов статей —
`data-testid="article-list-item"`. Тесты используют имеющиеся тестовые атрибуты, а заголовок проверяют по роли и видимому тексту. При развитии интерфейса полезно договориться об одном формате
тестовых атрибутов, например `data-testid`, и сохранять их значения стабильными.

Разметку следующих элементов стоит улучшить:

- У контейнера открытого виджета нет своего тестового атрибута или подходящей
  роли. Сейчас он находится через `header` и `data-test="button_close"`.
  `data-testid="support-widget"` на контейнере уберёт зависимость от вложенности.
- У закреплённой и популярных статей одинаковый `data-testid="article-list-item"`.
  Популярный список сейчас находится по тексту «Популярные статьи» и соседнему
  `ul`. `data-testid="popular-articles"` на списке позволит однозначно ограничить
  поиск без привязки к соседству элементов.
- Подтверждение cookies размечено как `div` с текстом «ОК»; в DOM есть скрытый
  дубликат. Для доступности и устойчивого поиска лучше использовать настоящую
  кнопку с именем «ОК» и оставить один интерактивный экземпляр.

Это рекомендации к разметке сайта, но так как мы не можем работать с кодовой базой проекта, то используем то, что существует, но не совсем корректно.
